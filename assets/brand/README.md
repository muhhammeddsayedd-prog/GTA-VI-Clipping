# Brand files

Minimal brand set: a gold six-pointed star (`#FFD400`, the `factory.accent_color` default) on the dark end-card colour `#0D0D12`.

| File | Use |
|---|---|
| `star.png` | 512x512, transparent background. Drawn above the brand name on the end card of every clip. |
| `logo.png` | 1024x1024, the star on the dark background (profile picture). |
| `logo.svg` | The same logo as a vector file. |

The files were drawn by a script for this project (no third-party artwork) and may be replaced: the factory reads `assets/brand/star.png` and renders without a logo when the file is missing.
